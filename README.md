# Ballistik Tank Fronts

Panzer-Simulation von Ballistik Studios mit echter Ballistik: Durchschlag, Splitter, Abpraller, Besatzung, Mehrspieler.

## ▶ Spielen (Windows)

1. **[Spiel herunterladen (BallistikStudios.zip)](https://github.com/steo324/Panzer/releases/latest/download/BallistikStudios.zip)**
2. ZIP entpacken (Rechtsklick → *Alle extrahieren*)
3. Im entpackten Ordner **`BallistikStudios.exe`** starten

Das Spiel aktualisiert sich danach von selbst, wenn es eine neue Version gibt.
Alle Versionen: [Releases](https://github.com/steo324/Panzer/releases)

> Der Button **„Code → Download ZIP“** enthält nur den Quellcode (Unity-Projekt), **nicht das fertige Spiel**.

## Mit Freunden spielen

- **Hosten:** im Menü *Selbst hosten* → der Beitrittscode oben im Bild geht an die Freunde.
- **Beitreten:** *Serverliste / Mit Code beitreten* → Code eingeben, oder einen Server aus der Liste anklicken.

## Steuerung (kurz)

W/A/S/D fahren · Maus zielen · Linksklick Kanone · Rechtsklick MG · Shift Visier · Q/E Entfernung · X Ansicht · G Kette reparieren · F Feuerlöscher · Esc Menü
